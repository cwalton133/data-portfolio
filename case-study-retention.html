Customer Retention & Churn Analytics

Banking / Customer Analytics Case Study

📉 Problem

A multinational bank was experiencing high customer churn with no visibility into which segments were at risk.

🧠 Approach

  • Built churn prediction logic using SQL + Python
  • Performed cohort & segmentation analysis
  • Developed Power BI dashboard for executives

💻 Sample SQL Logic

SELECT customer_id, COUNT(*) AS transactions, MAX(last_activity_date) AS last_seen, CASE WHEN DATEDIFF(day, MAX(last_activity_date), GETDATE()) > 90 THEN 'Churn Risk' ELSE 'Active' END AS status FROM transactions GROUP BY customer_id;
